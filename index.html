How it works

From model ID to planet-scale in an afternoon.

Step 01

Connect your model.

Paste a Hugging Face ID, push a container, or upload raw weights. Lumen benchmarks it on six chip types and picks the cheapest one that meets your latency target.

  • Automatic quantisation with quality checks
  • OpenAI-compatible API out of the box
$ lumen deploy meta-llama/Llama-4-70B
→ Fetching weights done (3.2 GB, 4.1 s)
→ Benchmarking H200, B200, MI325X …
→ Selected H200 · fp8 · 31 ms p50
→ Rolling out to 42 regions ✓
Live at https://acme.lumen.run/v1
Step 02

Go global by default.

Every deployment is multi-region from the first request. Lumen keeps replicas warm where your users are, and lets the rest of the planet sleep.

  • Anycast endpoint with regional pinning
  • Data residency controls per project
Step 03

See every millisecond.

Each request is traced from edge to token. Find the slow prompt, the expensive tenant, or the region that needs more headroom, in one click.

  • OpenTelemetry export to your stack
  • Quality evals on live traffic
